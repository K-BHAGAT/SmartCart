# SmartCart Segmentation System

## Overview
SmartCart Segmentation System is a machine learning project that analyzes customer purchasing behavior and segments customers into different groups using clustering techniques. The project helps businesses understand customer patterns for targeted marketing and better decision-making.

## Features
- Customer data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Customer segmentation using Machine Learning
- Cluster visualization and analysis
- Data-driven customer insights

## Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Technique
This project uses **K-Means Clustering** to group customers based on shopping behavior and spending patterns.

## Project Workflow
1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Selection
5. Customer Segmentation using K-Means Clustering
6. Cluster Visualization
7. Performance Analysis

## How to Run
1. Clone the repository

```bash
git clone <repository-link>
```

2. Install required libraries

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

3. Run Jupyter Notebook

```bash
jupyter notebook
```

## Output
The system groups customers into different segments based on purchasing behavior, helping businesses identify customer categories for personalized strategies.
